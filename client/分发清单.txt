AI Token 监控 — 分发包文件说明

══════════════════════════════════════
【发给最终用户时 — 保持极简】
══════════════════════════════════════
  ai-monitor.exe          主程序；第一次直接双击它，会自动打开安装/登录向导。
  开始使用.bat            新用户入口：配置后选择 VS Code / Cursor / 终端受管启动。
  低侵入监控.bat          打开时临时监控，关闭后恢复系统代理与环境变量。
  启动-VSCode监控.bat     仅受管启动 VS Code，不长期修改 IDE settings。
  启动-Cursor监控.bat     仅受管启动 Cursor，不长期修改 IDE settings。
  启动-PowerShell监控.bat 仅受管启动 PowerShell，适合 CLI 工具。
  启动-CMD监控.bat        仅受管启动 CMD，适合 CLI 工具。
  卸载.bat                完整卸载：证书、系统代理/PAC、环境变量、开机自启、IDE 代理等。
  修复网络.bat            异常退出或网络异常时的一键恢复入口。
  config.example.json     配置模板；正式配置由向导生成到 %APPDATA%\ai-monitor\config.json。
  使用说明.md             简短使用与排障说明。

  不要随包附带：
  - config.json（真实姓名、令牌、内网地址等都可能在里面）
  - 任何 .go 源码、go.mod、go.sum、*_test.go
  - 全局安装类 bat（全局安装、快速安装-系统代理等），避免用户默认走长期接管模式。

══════════════════════════════════════
【开发与维护仓库时 — 必须保留】
══════════════════════════════════════
  全部 .go 源文件、go.mod、go.sum、*_test.go
  build.bat / build.ps1   本机编译用
  打包-分发.bat           生成 dist\ai-monitor-分发版\ 极简分发目录

══════════════════════════════════════
【一键生成分发文件夹】
══════════════════════════════════════
  在 client 目录双击：打包-分发.bat
  会在上级目录生成 dist\ai-monitor-分发版\，仅含最终用户需要的低侵入运行文件。
