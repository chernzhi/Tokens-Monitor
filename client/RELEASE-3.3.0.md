# v3.3.0

首个支持自动更新的客户端版本。

- 新增：webwizard 控制台「关于」卡片，显示当前/最新版本，支持「检查更新」「立即更新」按钮
- 新增：后台每小时自动检测新版本（首次启动 10 秒后）；发现新版本时控制台横幅提示
- 新增：一键更新流程 — 下载 → SHA256 校验 → 备份 → 替换 exe → 自动重启 → 30 秒后清理备份
- 新增：服务端 `/api/release/client/latest` 与 `/download/{filename}` 接口
- 修复：updater 下载使用独立 HTTP 客户端，超时由 context 控制，避免大文件被 30s 客户端超时打断
- 安全：`--post-update` 仅接受 %TEMP% 下的路径；下载路径校验防穿越；SHA256 强制校验
